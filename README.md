# ArthikMitra 💰

### Financial Literacy Platform for Students

---

## 🧠 Tech Stack

Frontend: React + Vite
Backend: Node.js + Express
Database: MongoDB
AI: Google Gemini API

---

## ⚙️ Setup Instructions

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Archid-Haque/ArthikMitra.git
cd ArthikMitra
```

---

### 2️⃣ Install Dependencies

Run this in BOTH folders:

```bash
cd ArthikMitra-Backend
npm install

cd ../ArthikMitra-Frontend
npm install
```

---

## ▶️ Run the Project

### 🔹 Start Backend

```bash
cd ArthikMitra-Backend
node server.js
```

### 🔹 Start Frontend

```bash
cd ArthikMitra-Frontend
npm run dev
```

---

## 🌐 Access

After running:

👉 Open browser:
http://localhost:5173

---

## 📌 Notes

* `node_modules` will be created automatically after `npm install`
* Works on any system with Node.js installed
